# Bootstrap Practice

A responsive landing page built while learning Bootstrap 5.
This is a practice project and still a work in progress.

## What I practiced
- Bootstrap grid system and utilities
- Responsive navbar
- Custom CSS with CSS variables
- Footer layout with social icons (Font Awesome)

## Built with
- HTML5
- CSS3
- Bootstrap 5
- Font Awesome
